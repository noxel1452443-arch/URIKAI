# コンテンツレーティング質問メモ

IARC / Play の質問への回答の指針。金融チャート風だが **実取引・リアルマネーなし**。

| テーマ | 回答の目安 |
|---|---|
| 暴力 | なし |
| 性的表現 | なし |
| 言語 | なし〜軽微（ゲーム用語のみ） |
| 薬物・アルコール | なし |
| **ギャンブル／リアルマネー** | **なし**（仮想のゲーム内資産のみ。課金宝くじ等なし） |
| 恐怖・ホラー | なし |
| ユーザー生成コンテンツ | なし |
| オンライン交流 | なし |
| **金融・模擬投資** | 「シミュレーション／教育」系の設問があれば、**娯楽のタイミングゲーム**であり実口座・助言ではない旨を選択。迷ったら「金融取引機能なし」 |

年齢レーティングは質問結果に従う。意図としては全年齢〜低年齢帯。
