URIKAI カイのすみか — スプライト規格 / 生成 / モーション
======================================================

正本。旧 BED_SPRITE_SPEC.txt は本ファイルに吸収（寝床＝すみかの見た目グレード）。
ゲーム設計は store/SUMIKA_DESIGN.md。カイ本体セルは KAI_SPRITE_SPEC.txt。


0. ゴール
---------
ホームに「カイが住んでいる場所」が見えること。
数字やボタンではなく、家具イラスト＋カイの使い方で生活感を出す。

当面の成果物:
  A) すみか家具スプライト … 見た目グレードごと 1 枚（計 6）
  B) カイの占用ポーズ … sit / sleep（各 1。将来 nap 追加可）
  C) アプリ側の合成・出現ルール（本ファイル §5–6）


1. 見た目グレード（家具が変わる単位）
------------------------------------
Level は 0–99。イラストが切り替わる境界だけ用意する。
解放は出金回数ではなく「報酬受け取り → グレードアップ」（SUMIKA_DESIGN §3.2）。

進化軸: ほしぐさ → しきぬの＋白まくら → ふかふかくッション → うさぎドーム → 雪魔女の部屋
※ シルエット段階で別物。ペット家具サイズ。flat LCD。写実禁止。
※ 地平線（家具下の1本線）は描かない。
※ 現行正本: docs/kai-concepts/sumika-final/

  grade 1  Lv1–9      ほしぐさのねどこ             sumika_g1.png     【確定】
  grade 2  Lv10–24    あさのしきぬの               sumika_g2.png     【確定】
  grade 3  Lv25–44    ふかふかくッション           sumika_g3.png     【確定寄り】

※ グレード内の細かい Lv では絵を変えない。
※ inside は g4–g5 のみ必須。


2. セル規格（家具・必須）
------------------------
外観セル:
- キャンバス: 横長 240×120 px（生成は大きくてよい。最終この比率）
- 背景: 単色紙色のみ #C3CBA0。模様・UI・文字・値札・丸枠なし
- 床ライン: 下端から 12–16 px。全 grade で足元／接地を揃える
- 1ファイル = 家具のみ。カイは入れない（合成はアプリ）
- パレット: オリーブ LCD 3–4 階調のみ（カイ本体と同じ）。カラー禁止
- 輪郭: ほぼ 1px の濃い線。強いアンチエイリアス禁止

inside ビュー（g4–g5 のみ）:
- キャンバス: 正方形 120×120 px 目安（ホーム右上ポップ用）
- 背景 #C3CBA0 を外周に十分残す（紙色マージン必須）
- 部屋は円形 or 角丸の「のぞき窓」フレーム内
- カイは入れない（アプリが sit/sleep を重ねる）
- フルブリード禁止。かざりは窓内で完結


3. grade ごとのモチーフ／物語／カイ紐づけ
----------------------------------------
共通: 「ほしぐさ → しきぬの＋白まくら → ふかふかくッション → うさぎドーム → 雪魔女の部屋」

g0 なし … roam のみ

g1 ほしぐさのねどこ  【確定】
  干し草。外観のみ

g2 あさのしきぬの  【確定】
  麻のしき布＋薄い白まくら（左）。外観のみ

g3 ふかふかくッション  【確定寄り】
  同系立てかけまくら付き。外観のみ（座布団と呼ばない）

g4 うさぎドーム  【確定】
  両耳立ち。地平線なし。inside = 簡素

g5 雪魔女の部屋  【仮】
  片耳倒し＋濃い魔女帽子。ボディ模様なし。足元残雪のみ。
  inside = 家具UP＋冬（帽子／耳なし）

inside運用（g4–g5）:
  - のぞき見ステージ。部屋内ロアムなし。sit/sleep のみ固定パッド
  - 空いた居場所＋壁際の少ない小物。寝室丸ごと禁止

モーション共通ルール（実装）:
  - g1–g3: sit / sleep を家具に乗せる（enter／inside なし）
  - g4–g5: enter → insideビュー（固定パッド）→ exit
  - grade が上がるほど inside 滞在が長い
  - 受取ポップ中・シート中は inside 禁止


3.5 カイのすみか占用（設計メモ・2026-10）
----------------------------------------
狙い: 「家具の上にスタンプしただけ」に見せず、休んでいる／入っているが分かる。

A. 状態マシン（ホーム）
  roam  … 歩く／アイドル（既存）
  approach … すみかへ歩く（短い。任意）
  sit   … 腰かけ・浅く沈む
  sleep … 目閉じ・横たわり（またはドーム内では「なかで寝る」）
  exit  … g4+ のみ。なかみ解除→外へ出て roam

B. タイミング（目安）
  - ホーム静止 12–20 秒後、低確率で sit（Lv/grade で微増）
  - sit 4–8 秒 → 多くは roam、たまに sleep
  - sleep 18–35 秒、またはタップで起床
  - お給料ポップ表示中は sleep に入らない（受取を隠さない）
  - シート／グレード演出中は占用停止（シート用カイに交代）

C. タップ反応（わかりやすさ優先）
  - roam 中タップ … 既存セリフ
  - sit 中タップ … 短セリフ＋そのまま sit 継続 or 少し bounce
  - sleep 中タップ … 起床（sleep→roam）＋寝言1行
    「ん…まだねる」「お給料？」「もうすこしだけ…」など
  - すみか家具タップ … シート（カイ占用中でも可。カイはシート側へ）

D. イラスト差分（必要最小）
  新規: kai_pose_sit / kai_pose_sleep（家具は含めない）
  既存 face 流用可: sleep は目閉じ（cry/think ではなく専用が望ましい）
  g1–g3: 家具の上に sit/sleep をオフセット合成（乗る点は grade ごと定数）
  g4–g5: 外観の入口前で approach → 消えて inside ポップに小さな sit/sleep
         （外観の上にカイを乗せ続けない＝穴に入った感）

E. 違和感を減らす合わせ方
  - スケール: カイは家具幅の 35–45% 程度（ドームより小さく）
  - 足元合わせ: 家具の接地ライン＋数 px 沈める（浮かせない）
  - Z順: 家具の後ろ壁 < カイ < 家具の手前リム（ドーム入口はリム前面）
    ※ 最初は「カイを家具の少し手前／少し沈める」だけでよい
  - 影: 1px 程度の接地影があれば十分
  - 受取ポップと被らないよう、占用中はポップを家具上端よりさらに上へ

F. 段階実装
  1) sit/sleep スプライト生成
  2) g1–g3 のみ家具上合成＋タップ起床
  3) g4–g5 inside 合成（固定パッド）
  4) approach／入口リムの前後関係は後回し可

5. アプリ上の置き方
-------------------
5.1 ホーム
  - すみかは床面の固定スポット（BottomCenter 付近）。ラベル文字は出さない
  - 受取ポップは家具の「上」に浮かせる（くっつけない。ギャップ 20–28dp 目安）
  - ポップはボタン枠にしない（コイン／報酬感。二重線枠は使わない）

5.2 詳細シート
  - 家具を大きく中央に
  - シート表示中はホーム歩行カイを隠す
  - シート左上にカイ（右向き・小さめ）＋シート専用セリフ
  - レベルアップは確認ステップ付き（カイが元手減少を言う）

5.3 合成レイヤ（将来）
  下: 家具スプライト
  上: カイ占用ポーズ（sit/sleep）を家具の「乗る点」にオフセット配置
  乗る点は grade ごとに定数（枕寄り／マット中央など）


6. カイがすみかを使うタイミング（モーション方針）
----------------------------------------------
ホーム常駐カイは今どおり歩く／ドラッグできる。
それに加え、すみか Lv≥1 のときだけ「占用」を混ぜる。

6.1 状態
  roam   … 現行の歩行・アイドル（デフォルト）
  sit    … すみかに座る（短め）
  sleep  … 寝る（長め・触るまで or タイムアウト）

6.2 遷移（叩き台）
  - roam アイドルが 12–20 秒続いたら、低確率で sit へ（Lv が高いほど少し上がる）
  - sit を 4–8 秒 → 高確率で roam に戻る／低確率で sleep
  - sleep は 15–40 秒、またはプレイヤータッチで roam（起きて一言）
  - 受取ポップ表示中は sleep に入らない（報酬を隠さない）
  - シート表示中は占用モーション停止（シート用カイに交代）

6.3 見た目の約束
  - sit/sleep 中はドラッグ開始で即 roam（つかめる）
  - 占用中もタップでセリフは可（寝言バリエーションは後で）
  - グレードが上がると「寝る場所が豪華」に見えるだけで、モーション種類は増やさない

6.4 シート上のカイ（実装優先・イラスト前でも可）
  - 既存 GuideBuddyFace を左右反転して右向き
  - セリフはシート文脈専用（残高・無理しすぎ注意・購入確認）
  - 家具イラストが来るまで Canvas プレースホルダでよい


7. 受取ポップのビジュアル方針（UI）
----------------------------------
やらない:
  - lcdDoubleBorder のチップ（ボタンに見える）
  - 家具に密着した配置

やる:
  - 家具から離して浮遊
  - 「+¥」を主役。小さな円コイン（Ink 塗り／穴あき円）を添えてもよい
  - ゆっくり上下に浮く（脈動スケールよりボブライン）
  - タップで上へフェードアウト → 口座カウントアップへバトン


8. チェックリスト（grade ごと）
------------------------------
[ ] 背景は単色紙色だけ → 透過済み
[ ] 床ラインが他 grade と一致
[ ] 輪郭がはっきり（塗りつぶしシルエットでない）
[ ] 文字・値札・フレーム・カイなし
[ ] ホーム小表示でも判別できるシルエット差
[ ] シート大表示でもドットが破綻しない


9. 作業順（推奨）
----------------
1. g1（草）と g4（ふとん）を先に作る … 仮住まい vs 生活感の対比でトーン確定
2. g0 / g2 / g3 / g5 を同構図で埋める
3. アプリで Image 差し替え＋乗る点の仮オフセット
4. kai_pose_sit / sleep → drawable 接続済。ホーム占用実装済
   - 位置: 家具 dp 基準で足元合わせ（端末差を抑える）
   - 移動: すみかへは直線距離
   - g1–g3: 家具上 sit/sleep
   - g4–g5: 入口→カイ非表示＋外観右上に内観ピーク（切替ではない）
   - ホーム家具スケール: g2/g3=1.5×、g4/g5=2×（シートに inside は出さない）
5. 受取ポップ・シートカイセリフはイラストと並行で UI 調整可
