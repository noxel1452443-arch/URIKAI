URIKAI カイのすみか — スプライト規格 / 生成 / モーション
======================================================

正本。旧 BED_SPRITE_SPEC.txt は本ファイルに吸収（寝床＝すみかの見た目グレード）。
ゲーム設計は store/SUMIKA_DESIGN.md。カイ本体セルは KAI_SPRITE_SPEC.txt。


0. ゴール
---------
ホームに「カイが住んでいる場所」が見えること。
数字やボタンではなく、家具イラスト＋カイの使い方で生活感を出す。

当面の成果物:
  A) すみか家具スプライト … 見た目グレードごと 1 枚（計 6）
  B) カイの占用ポーズ … sit / sleep（各 1。将来 nap 追加可）
  C) アプリ側の合成・出現ルール（本ファイル §5–6）


1. 見た目グレード（家具が変わる単位）
------------------------------------
Level は 0–99。イラストが切り替わる境界だけ用意する。
解放は出金回数ではなく「報酬受け取り → グレードアップ」（SUMIKA_DESIGN §3.2）。

進化軸: わらのす → ざぶとん → ドーム → キャラモチーフ小屋 → さらに特別なモチーフ
※ g4/g5 は「同じドームの豪華版」にしない。シルエット段階で別物に見えること。
※ キルティングボタン／ドット凹凸禁止。人間の洋館スケール禁止（常にペット家具サイズ）。
※ 住み心地が上がること＋外観モチーフで変化。中に入れる穴（黒い入口）は g3 以降共通。

  grade 0  Lv0        なし（ホーム非表示）
  grade 1  Lv1–9      わらのす                     sumika_g1.png
  grade 2  Lv10–24    ふかふかざぶとん             sumika_g2.png
  grade 3  Lv25–44    ちいさなドーム               sumika_g3.png + sumika_g3_inside.png
  grade 4  Lv45–69    みみや                         sumika_g4.png + sumika_g4_inside.png
  grade 5  Lv70–99    ヘッドセットハウス           sumika_g5.png + sumika_g5_inside.png

--- 確定方向（2026-10）---
g3 ドーム（入れる）→ g4 みみや（耳＝建築）→ g5 ヘッドセットハウス（通信本拠）
禁止: 顔パーツ移植／キルティング／人間洋館／幕＋クッション／耳の同語反復強化。

g4 みみや
  - やわらかい丸〜俵型ボディ。耳は屋根／ひさし（片耳起立・片耳倒れ）
  - 入口穴正面。顔ディテールなし

g5 ヘッドセットハウス（案H1）
  - ボディは g4 より少し大きい俵〜ドーム（ペット家具サイズ）
  - 頭頂に太いヘッドバンドの弧
  - 向かって右にイヤーカップがせり出す
  - 細いブームマイクが入口脇まで伸び、マイク先が入口を指す／守る
  - 耳は小さく後ろに控える（主役はヘッドセット）
  - 正面に暗い入口穴（奥行き＝部屋）。顔・目・口は描かない
  - カイ本人は外観に入れない

※ グレード内の細かい Lv では絵を変えない（数値だけ上がる）。
※ キャップ到達時は次Lvを見せない。次家具は報酬受け取り後にグレードアップボタンで。
※ g3–g5 は「外観」と「inside ビュー」の2アセット必須。


2. セル規格（家具・必須）
------------------------
外観セル:
- キャンバス: 横長 240×120 px（生成は大きくてよい。最終この比率）
- 背景: 単色紙色のみ #C3CBA0。模様・UI・文字・値札・丸枠なし
- 床ライン: 下端から 12–16 px。全 grade で足元／接地を揃える
- 1ファイル = 家具のみ。カイは入れない（合成はアプリ）
- パレット: オリーブ LCD 3–4 階調のみ（カイ本体と同じ）。カラー禁止
- 輪郭: ほぼ 1px の濃い線。強いアンチエイリアス禁止

inside ビュー（g3–g5）:
- キャンバス: 正方形 120×120 px 目安（ホーム右上ポップ用）
- 背景 #C3CBA0 を外周に十分残す（紙色マージン必須。端まで部屋を塗りつぶさない）
- 部屋は円形 or 角丸の「のぞき窓」フレーム内に収める（g4 inside 準拠）
- カイは入れない（アプリが小さなカイ顔／sit を重ねる）
- g5 でもフルブリード禁止。かざりは窓内で完結


3. grade ごとのモチーフ／物語／カイ紐づけ
----------------------------------------
共通: 「す → ざぶとん → ドーム → みみや → みみやねごてん」
ホーム小表示でもシルエット段階で別物に見えること。

g0 なし（ホーム非表示）
  モチーフ: 場所だけある床
  カイ: roam のみ

g1 わらのす  … 鳥の巣風・仮住まい  【v2 OK】
  モチーフ: 浅いボウル型のわら／草のす
  カイ: sit/sleep をすに乗せる

g2 ふかふかざぶとん  … 心地よさUP  【v2 OK】
  モチーフ: 柔らかいクッションねぐら（マット禁止）
  カイ: 中央に沈む sit / 半分埋もれ sleep

g3 ちいさなドーム  … 初めて「入れる」  【v2 OK】
  モチーフ: 正面に黒い入口穴のあるペットドーム
  内装: 簡素な床＋小まくら（のぞき窓フレーム＋外周マージン）
  カイ: enter → insideビュー → exit
  ルール: 受取ポップ／シート中は inside 禁止

g4 みみや  … 耳を建築化した小屋
  モチーフ: 俵型ボディ＋耳（片耳起立／片耳ひさし）
  外観: 顔パーツなし。耳は屋根／ひさし。入口穴は正面。キルティング禁止
  内装: のぞき窓＋居場所パッド空け。壁際小物1点
  カイ: enter → inside（固定パッド）

g5 みみやねごてん  … 耳が屋根になる最上
  モチーフ: 巨大な両耳が天蓋屋根として合体し、下に巣ボディ＋暗い入口
  外観: 家具のみ（中にカイを描かない）。ペットサイズ。あっと驚くシルエット
  内装: 同パッド位置。壁の厚み・まくらで差。舞台カーテン禁止
  カイ: inside 出現率最高

inside運用（確定・推奨）:
  - inside ポップは「のぞき見ステージ」。カイは部屋内を歩き回らない
  - カイは居場所パッドに sit / sleep の2ポーズだけを合成
  - 理由: ホーム隅の小UIでは移動経路が取れず、家具だらけだと不自然になる
  - よって inside 絵は「空いた居場所＋壁際の少ない小物」が正。寝室丸ごと禁止
  - g3→g5 の差は外観シルエット＋insideのかざり密度。居場所の位置は全 grade で揃える

モーション共通ルール（実装）:
  - g1–g2: sit / sleep を家具に乗せる
  - g3–g5: enter → insideビュー（固定パッド）→ exit
  - grade が上がるほど inside 滞在が長い
  - 受取ポップ中・シート中は inside 禁止

5. アプリ上の置き方
-------------------
5.1 ホーム
  - すみかは床面の固定スポット（BottomCenter 付近）。ラベル文字は出さない
  - 受取ポップは家具の「上」に浮かせる（くっつけない。ギャップ 20–28dp 目安）
  - ポップはボタン枠にしない（コイン／報酬感。二重線枠は使わない）

5.2 詳細シート
  - 家具を大きく中央に
  - シート表示中はホーム歩行カイを隠す
  - シート左上にカイ（右向き・小さめ）＋シート専用セリフ
  - レベルアップは確認ステップ付き（カイが元手減少を言う）

5.3 合成レイヤ（将来）
  下: 家具スプライト
  上: カイ占用ポーズ（sit/sleep）を家具の「乗る点」にオフセット配置
  乗る点は grade ごとに定数（枕寄り／マット中央など）


6. カイがすみかを使うタイミング（モーション方針）
----------------------------------------------
ホーム常駐カイは今どおり歩く／ドラッグできる。
それに加え、すみか Lv≥1 のときだけ「占用」を混ぜる。

6.1 状態
  roam   … 現行の歩行・アイドル（デフォルト）
  sit    … すみかに座る（短め）
  sleep  … 寝る（長め・触るまで or タイムアウト）

6.2 遷移（叩き台）
  - roam アイドルが 12–20 秒続いたら、低確率で sit へ（Lv が高いほど少し上がる）
  - sit を 4–8 秒 → 高確率で roam に戻る／低確率で sleep
  - sleep は 15–40 秒、またはプレイヤータッチで roam（起きて一言）
  - 受取ポップ表示中は sleep に入らない（報酬を隠さない）
  - シート表示中は占用モーション停止（シート用カイに交代）

6.3 見た目の約束
  - sit/sleep 中はドラッグ開始で即 roam（つかめる）
  - 占用中もタップでセリフは可（寝言バリエーションは後で）
  - グレードが上がると「寝る場所が豪華」に見えるだけで、モーション種類は増やさない

6.4 シート上のカイ（実装優先・イラスト前でも可）
  - 既存 GuideBuddyFace を左右反転して右向き
  - セリフはシート文脈専用（残高・無理しすぎ注意・購入確認）
  - 家具イラストが来るまで Canvas プレースホルダでよい


7. 受取ポップのビジュアル方針（UI）
----------------------------------
やらない:
  - lcdDoubleBorder のチップ（ボタンに見える）
  - 家具に密着した配置

やる:
  - 家具から離して浮遊
  - 「+¥」を主役。小さな円コイン（Ink 塗り／穴あき円）を添えてもよい
  - ゆっくり上下に浮く（脈動スケールよりボブライン）
  - タップで上へフェードアウト → 口座カウントアップへバトン


8. チェックリスト（grade ごと）
------------------------------
[ ] 背景は単色紙色だけ → 透過済み
[ ] 床ラインが他 grade と一致
[ ] 輪郭がはっきり（塗りつぶしシルエットでない）
[ ] 文字・値札・フレーム・カイなし
[ ] ホーム小表示でも判別できるシルエット差
[ ] シート大表示でもドットが破綻しない


9. 作業順（推奨）
----------------
1. g1（草）と g4（ふとん）を先に作る … 仮住まい vs 生活感の対比でトーン確定
2. g0 / g2 / g3 / g5 を同構図で埋める
3. アプリで Image 差し替え＋乗る点の仮オフセット
4. kai_pose_sit / sleep を生成して占用モーション接続
5. 受取ポップ・シートカイセリフはイラストと並行で UI 調整可
